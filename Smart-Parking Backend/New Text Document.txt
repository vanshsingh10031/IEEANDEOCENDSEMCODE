| Internal ID | Human Label | Sensor Pin | LED Pin |
| ----------- | ----------- | ---------- | ------- |
| **S1**      | **A1**      | D2         | D5      |
| **S2**      | **A2**      | D3         | D6      |
| **S3**      | **A3**      | D4         | D7      |


| Benefit                           | Explanation                                        |
| --------------------------------- | -------------------------------------------------- |
| **Simple to show in UI**          | Straight 3 slots in a row: A1, A2, A3              |
| **Makes sense physically**        | Can label each slot on the cardboard with A1/A2/A3 |
| **Scalable**                      | If you add B row later, IDs + logic stay same      |
| **Hardware mapping stays stable** | UI changes don’t affect ESP pin logic              |
